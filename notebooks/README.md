# Notebooks

Ten katalog zawiera notebooki Jupyter do analizy i eksploracji danych.

## Struktura

Notebooki powinny być nazywane z prefiksem numerycznym dla zachowania kolejności:

```
01_data_exploration.ipynb
02_data_cleaning.ipynb
03_feature_engineering.ipynb
04_modeling.ipynb
05_evaluation.ipynb
```

## Dobre praktyki

- Każdy notebook powinien mieć jasny cel i dokumentację
- Czyść outputy przed commitowaniem (opcjonalnie)
- Używaj relative paths do plików
- Importuj funkcje z modułów src/ zamiast duplikować kod
- Dodawaj markdown cells z opisami i wnioskami
